## 🎯 仓库目标
本仓库用于收集和维护 Agent / Skill 实践：  
**快速初始化** ⚡ | **流程标准化** 🧩 | **结果可检查** ✅

---

## 🧠 四个 Skill 一览

### 1) 📘 Exam Helper
`学习 / 考试任务` 的流程化支持  
- 搭建学习与答题工作区  
- 提供模板、示例和启动文件  
- 降低准备成本，提高执行效率

```bash
python3 Exam_Helper/scripts/init_exam_workspace.py
```

---

### 2) 📝 Report Workflow
`报告生成` 的标准化工作流  
- 从生成到检查的一体化流程  
- 强调结构清晰、质量可复核  
- 适合稳定交付与团队协作

```bash
python3 report-workflow/scripts/init_report_project.py
```

---

### 3) 🐉 HydraProject
`通用项目` 的技能化组织方案  
- 支持多模块任务拆分  
- 沉淀可复用流程与模板  
- 方便快速迁移到新项目

---

### 4) 🧩 第四个 Skill（按仓库实际名称补充）
- 建议一句话写法：**场景 + 动作 + 结果**  
- 例：面向 XX 场景，自动化完成 XX，最终输出 XX

---

## 🗂️ 项目结构
- `Exam_Helper/`：考试/学习相关 skill、模板、示例  
- `report-workflow/`：报告生成与质量检查流程  
- `HydraProject/`：项目化 skill 与说明  
- `*/scripts/`：初始化脚本  
- `*/templates`、`*/assets/starter_files`：模板与启动文件

---

## ⚙️ 使用方式
1. 阅读对应目录下的 `README.md` / `SKILL.md`  
2. 运行 `scripts/` 初始化  
3. 按模板填充内容并执行  
4. 持续沉淀为可复用 skill ♻️
