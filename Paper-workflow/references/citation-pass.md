# Citation Pass

Citation work is disabled unless the user explicitly executes a Citation task.

Start only from requests such as:

```text
执行 Citation Task 2
```

Read:

- `Codex-Paper/User-Interaction/Citation/Citation-Interaction.md`;
- only the requested Citation task block;
- `Paper/refs.bib` only to verify cite keys;
- target LaTeX files explicitly named by the task.

## Rules

- Use only papers, cite keys, BibTeX entries, or article materials explicitly provided or allowed by the task.
- Do not browse for papers unless the user explicitly authorizes browsing.
- Do not choose arbitrary entries from `refs.bib`.
- Insert citations at natural positions with minimal text changes.
- Add only small connective wording when needed.
- You may weaken overly absolute wording without changing the main meaning.
- Do not rewrite the paragraph's main logic.
- Do not change contributions.
- Do not change method definitions.
- Do not change experimental conclusions.
- If a provided citation cannot rigorously support the claim, report a blocker instead of forcing the citation.

`Citation-Note.md` follows the same default as all Note files: do not read or edit it without explicit authorization.
