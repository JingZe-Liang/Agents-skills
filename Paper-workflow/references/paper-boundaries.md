# Paper Boundaries

`Codex-Paper/Paper/` is the only formal paper area and may be an Overleaf Git repository.

Allowed in `Paper/`:

- formal LaTeX;
- formal figures;
- formal tables;
- `refs.bib`;
- templates, style files, class files, macros, and venue resources;
- files required for compilation.

Forbidden in `Paper/`:

- user/AI discussion records;
- unconfirmed ideas;
- temporary notes;
- workflow instructions;
- internal plans;
- intermediate drafts;
- automatic task logs;
- `Interaction` or `Note` files.

## Existing Templates

If `Paper/` already has template content or `.git`:

- do not overwrite `main.tex`;
- do not delete or move style/template files;
- do not automatically refactor the template;
- do not split a single-file paper into sections without an explicit task;
- create only missing safe directories when needed;
- follow the user's actual template structure over the default mapping.

## Minimal Skeleton

Only when `Paper/` is missing or empty, create the minimal skeleton. The skeleton must contain no paper claims, no method descriptions, no experimental results, no invented authors, and no citations.
